# حاسبة الكابتن (Android)

## التشغيل
1. نزّل Android Studio (آخر إصدار) وافتح فولدر CaptainProfit.
2. استنى Gradle Sync يخلص (محتاج إنترنت أول مرة).
3. وصّل موبايلك (USB Debugging) واضغط Run، أو Build > Build APK(s).
4. افتح التطبيق، اضبط إعدادات عربيتك، اضغط "اسمح بالظهور فوق التطبيقات"، بعدين "شغّل النافذة العايمة".
5. افتح إن درايف. دوس على زرار 💰 العايم وادخل السعر والمسافة.

## ملاحظات
- التطبيق مش بيقرا شاشة إن درايف. الإدخال يدوي وسريع.
- القيم الافتراضية (بنزين 20، عمولة 10%...) أمثلة، عدّلها.
